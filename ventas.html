Ruta recomendada

Cómo lo montamos

  • Gumroad/Payhip para ebooks y ventas rápidas.
  • KDP para edición física bajo demanda.
  • Enlace directo desde la web del autor.
  • Sin exponer datos sensibles del pago en el navegador.
EPUB

Venta directa del ebook

La compra del ebook se gestiona desde Gumroad o Payhip. La web solo enlaza a la compra segura.

Cambia este enlace por tu producto real en Gumroad/Payhip.

Payhip

Alternativa de venta

Payhip es muy útil si prefieres un flujo más simple para ebooks y descargas digitales.

Ir a Payhip

También puedes usar Payhip con una landing mejorada y un enlace único por libro.

Ir a KDP
